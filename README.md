# AI Hub — Portfolio Recreation

A sanitised, independently built recreation of selected product patterns from an enterprise AI knowledge hub. It demonstrates product discovery, editorial storytelling, responsive interaction design, and accessible front-end implementation using fictional content.

## Important disclosure

This repository **does not contain the original application, source code, data, branding, infrastructure, or proprietary information**. Product names, metrics, people, and written content in this demo are fictional. It is not affiliated with or endorsed by the organisation for which the original work was performed.

## What this demo showcases

- A clear information architecture for an internal AI hub
- Searchable product discovery with lightweight client-side interaction
- Responsive product and editorial card systems
- Accessible landmarks, labels, focusable controls, and semantic content
- A polished interface built in Next.js and TypeScript

## Run locally

```bash
pnpm install
pnpm dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Portfolio context

The production platform that inspired this recreation is confidential. This demo was built separately to communicate the design thinking and front-end skills involved without disclosing company-owned material.

## Tech stack

Next.js · React · TypeScript · CSS
